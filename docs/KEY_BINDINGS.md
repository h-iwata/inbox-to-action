# キーボードショートカット

<!-- このファイルは `npm run docs:keybindings` で自動生成されます。直接編集しないでください。 -->
<!-- 定義元: src/config/commands.ts -->

デスクトップ（画面幅 768px 以上）でのみ有効です。
入力欄にフォーカスがある間・IME 変換中・キーを押しっぱなしにしている間は発火しません。

## モード切り替え

| キー | 動作 | 有効なモード |
| --- | --- | --- |
| `Tab` | 次のモードへ | 全モード |
| `Shift + Tab` | 前のモードへ | 全モード |

## 分類

| キー | 動作 | 有効なモード |
| --- | --- | --- |
| `a` / `←` | 仕事に分類 | 分類 |
| `d` / `→` | 生活に分類 | 分類 |
| `w` / `↑` | 学習に分類 | 分類 |
| `s` / `↓` | 趣味に分類 | 分類 |

## 実行

| キー | 動作 | 有効なモード |
| --- | --- | --- |
| `Space` | 実行中タスクを完了 | 実行 |
| `1` | 仕事のタスクに切り替え | 実行 |
| `2` | 生活のタスクに切り替え | 実行 |
| `3` | 学習のタスクに切り替え | 実行 |
| `4` | 趣味のタスクに切り替え | 実行 |
